# The Joy of Travel

A responsive static travel website for business travel, group travel, and vacation travel.

## Files
- `index.html` — home page
- `about.html`
- `business-travel.html`
- `group-travel.html`
- `vacation-travel.html`
- `contact.html`
- `faq.html`
- `css/style.css`
- `js/script.js`
- `images/` — place for local images

## Before going live
1. Replace the placeholder email and phone number.
2. Replace `REPLACE_ME` in `contact.html` with your Formspree form ID, or connect another form service.
3. Replace booking/CTA links with your actual InteleTravel booking URL when ready.
4. Review all business claims, contact details, policies, and testimonials before publishing.
5. For production, consider downloading/licensing your preferred images into `images/` rather than relying on the demo Unsplash hero URL.

## GitHub
Create a repository named `the-joy-of-travel`, upload the contents of this folder, and commit the files.

## Vercel
In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy. This is a static site, so no build command is required.

## Custom domain
After deployment, open the Vercel project settings and add your domain. Follow the DNS records Vercel provides.

## Important
The included form is a placeholder until a real form endpoint is configured. Do not advertise a working booking or inquiry process until it has been tested.
